# 融資準備チェックリストと初期資金計画（内部用）

「融資を受けるために何が必要か」の全リストと、
「このプロジェクトを初手いくらで動かせるか」の資金計画。
本リポジトリは製品開発〜法人化〜創業融資までを含む創業プロジェクトとして運用する。

---

## 第1部: 融資（公庫）を受けるために必要なもの 全リスト

### A. 必須書類

- □ 創業計画書（公庫様式）― 下書き済み: `創業計画書_下書き.md`（【要記入】欄を埋める）
- □ 借入申込書（公庫様式・インターネット申込なら画面入力）
- □ 通帳のコピー（自己資金の確認用。**直近6ヶ月以上**・ネット銀行は入出金明細PDF）
- □ 資金使途の根拠となる見積書・価格表（広告・外注・資材など主要な使い道の分）
- □ 本人確認書類（運転免許証等）
- □ 法人の履歴事項全部証明書（登記後に法務局で取得）
- □ 法人の印鑑証明書・定款の写し
- □ （自宅兼事務所が賃貸の場合）賃貸借契約書の写し
- □ （売上が既にある場合）請求書控え・入金記録 ― **最強の添付書類**

### B. 任意提出だが審査を強くする書類（この事業はすべて揃えられる）

- □ 導入協力校との覚書・契約書（有償実績の証明）
- □ 製品資料一式（LP印刷・提案書PDF・製品パッケージの紹介）
- □ 検証ログ（実物ファイル検証・異常系テスト15項目）
- □ 導入前後の作業時間の実測記録（協力校から取得）
- □ 販売戦略・3年ロードマップ（販売戦略メモの表）

### C. お金まわりの「状態」（書類より先に効く）

- □ 自己資金が借入希望額の1/3ある（なければ希望額を下げる: Phase 0-b）
- □ 自己資金がコツコツ貯めた履歴になっている（毎月の積立記帳）
- □ 申請直前の大口入金（見せ金）がない
- □ 税金・国民年金・健康保険の滞納がない（個人事業の確定申告も済んでいる）
- □ 家賃・携帯・カードの支払い遅延がない
- □ CIC（信用情報）を自己開示して事故情報がないことを確認済み（スマホから千円程度）

### D. 申請前にやっておく行動

- □ **長山高校の有償成約**（29,800円の覚書＋入金）― 最優先
- □ 法人口座（川崎信金）を開設し、売上の入金を通す
- □ 公庫の「事業資金相談ダイヤル」または支店窓口で事前相談（無料・匿名可）
- □ 税理士（認定経営革新等支援機関）に1回相談しておく（制度融資の布石にもなる）
- □ 創業計画書の数字を暗記する（単価・校数計画・月商・経費・返済額）

### E. 面談の準備

- □ 事業を3分で説明する練習（製品デモをタブレット/PCで見せられると強い）
- □ 想定問答: 「なぜこの事業か」「競合は」「売れなかったら」「赤字の間の生活費は」
- □ 数字は資料を見ずに言えるように（見ながらだと「計画が他人事」に見える）
- □ 服装は清潔なビジネスカジュアル以上。時間厳守

## 第2部: 初手にいくらあるといいか（3段階の資金計画）

前提: テスト用ノートPC2台は保有済み（機材投資ほぼ不要）。
この事業の初期費用は業界でも最軽量級で、それ自体が強み。

### Level 1: 最小で動き出す ― 手元 約10万円

個人事業のまま営業を開始する場合の実費。設立は後回しにしても営業はできる。

| 費目 | 金額 | 備考 |
|---|---|---|
| Microsoft 365（Office正規版） | 年 約2.5万 | 実機デバッグ・出荷用xlsm作成に必須 |
| 独自ドメイン＋メール | 年 約1万 | 会社メールの信用（フリーメール卒業） |
| USB・封筒・ラベル・送料 | 約1万 | 2校分の郵送キット |
| 印刷費・名刺 | 約1万 | 手順書・提案書・チェックシート |
| 交通費（商談・レクチャー） | 約2万 | 都内10往復分 |
| 予備 | 約2.5万 | |
| **合計** | **約10万円** | |

→ **10万円あれば長山の成約〜導入までは完走できる。**

### Level 2: 法人を作って進める ― 手元 約60〜80万円

| 費目 | 金額 | 消えるお金か |
|---|---|---|
| 設立実費（電子定款・自力） | 約20万 | 消える |
| Level 1の初動経費 | 約10万 | 消える |
| 資本金（そのまま会社の運転資金になる） | 30〜50万 | **消えない**（会社の口座に残る） |
| **必要な手元現金** | **約60〜80万** | 実際に消えるのは約30万 |

→ 資本金は「支払い」ではなく「自分の会社への移動」。
実質コストは約30万で株式会社＋初動営業まで行ける。

### Level 3: 融資をフルに引く理想形 ― 手元 約100〜120万円

- 自己資金100万円を見せられる状態（＝資本金100万で設立するのが素直）
- → 公庫に300万円申請 → **総事業資金400万円**でスタート
- 400万の使い道: 営業60万・広告60万・外部委託60万・役員報酬/予備220万
  （売上が育つまでの12ヶ月を役員報酬でしのげる＝営業に集中できる）

### 結論

| いま用意できる額 | 進め方 |
|---|---|
| 〜10万 | 個人事業のまま長山を成約し、売上と積立で貯めてからLevel 2へ |
| 60〜80万 | 法人設立まで一気に。融資は入金実績を6〜12ヶ月作ってから100〜200万申請 |
| 100万〜 | 設立→即申請の最短ルート（長山成約を先に済ませること） |

**推奨: まず10万円で「売上のある個人事業」を作り、覚書と入金を持って
Level 2/3 に進む。** 初手の大金より、有償実績が先。これがこの事業の
最大の強み（初期費用が軽く、実績を先に作れる）を活かす順番。

## 資金の使い道 優先順位（迷ったらこの順）

1. Microsoft 365（実機デバッグと出荷用xlsmが作れないと何も始まらない）
2. 独自ドメインメール（見積書・請求書の信用に直結）
3. USB・印刷（長山への納品資材）
4. 交通費（商談は対面が決まる）
5. 覚書の専門家確認（行政書士スポット1〜3万・成約が見えてからでよい）
6. 広告費（LP改修・Web広告は融資後でよい。それまでは紹介と研究会）
